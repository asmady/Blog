Mulai Ngeblog dari HP Android

4 Oktober 2026 · 5 menit baca

Banyak orang mengira ngeblog itu harus pakai laptop dan hosting berbayar. Padahal HP Android plus Termux sudah cukup untuk membuat website statis dan memajangnya ke internet secara gratis.

Yang dibutuhkan

Tiga hal saja: Termux terinstall, Git untuk meng-upload, dan satu repository kosong di GitHub Pages.

Upload ke internet

cd ~/blog-asmady
git init && git add .
git commit -m "artikel baru"
git remote add origin https://github.com/USER/REPO.git
git push -u origin main

Kenapa static?

Website static tidak butuh database maupun server. Semua isinya file HTML, CSS, dan JavaScript, jadi cepat, gratis, dan hampir mustahil error.

File yang sudah ter-upload ke GitHub Pages akan bisa diakses kapan saja, tanpa perlu HP menyala.

Cron Job yang Jalannya Otomatis

3 Oktober 2026 · 6 menit baca

Android memang bukan server, tapi Termux mengubahnya jadi lingkungan yang cukup mampu untuk menjalankan tugas terjadwal. Dengan begitu, HP yang tergeletak di saku tetap bisa mengerjakan sesuatu tanpa disentuh.

Cron itu apa

Cron adalah penjadwal bawaan Unix yang menjalankan perintah pada waktu tertentu. Contoh: setiap jam pagi, setiap Senin, atau setiap lima belas menit.

Menggabungkan cron dengan AI

Yang membuat cron terasa pintar adalah ketika perintah yang dijalankan tidak sekadar script, tapi agent AI yang bisa berpikir. Hasilnya dikembalikan lewat Telegram, jadi laporan sampai ke tangan tanpa perlu membuka aplikasi apa pun.

*/15 * * * * ./cek_harga.sh

Batas yang harus diterima

Termux punya batas nyata. Android bisa Hemat baterai atau membekukan aplikasi di latar belakang, jadi proses cron tidak dijamin hidup 24 jam. Untuk kebutuhan yang harus selalu nyala, lebih baik andalkan hosting.

Yang bisa dijalankan di HP: laporan, pengingat, pengecekan data. Yang tidak: mengelola aplikasi lain, membaca pesan, atau mengendalikan layar.

Kendalikan Program dari Telegram

5 Oktober 2026 · 6 menit baca

Program yang jalan sendiri itu memangADA gunanya. Tapi program yang jalan sendiri dan bisa diperintah dari jauh adalah masalah yang berbeda. HP tidak perlu disentuh untuk menjalankan, dan tidak perlu dibuka untuk mengendalikan.

Arsitektur paling sederhana

Tiga bagian, semuanya berjalan di HP:

  1. Mesin — program yang mengerjakan tugas, misalnya memeriksa harga setiap 5 menit
  2. Penjadwal — runit, penjadwal bawaan Termux yang menyalakan mesin otomatis setiap HP dinyalakan ulang
  3. Antarmuka — program kecil yang membaca pesan Telegram lalu memanggil mesin

Bagian ketiga yang paling sering dilupakan. Tanpa itu, satu-satunya cara mengatur program adalah membuka Termux dan mengetik perintah.

Kenapa Telegram, bukan aplikasi sendiri

Alasannya praktis, bukan teknis:

  • Sudah ada di HP, tidak perlu memasang apa pun
  • Bisa diakses dari mana saja, browser smartphone pun cukup
  • Bisa menulis perintah, bukan hanya menampilkan angka
  • Notifikasi sampai dalam hitungan detik

Aturan emas: satu bot, satu poller

Ini yang paling sering menimbulkan masalah. Setiap token bot Telegram hanya bisa dibaca oleh satu program pada satu waktu. Kalau dua program berjalan bersamaan memakai token yang sama, salah satunya merebut pesan, dan program yang Beautynamed ikut kehilangan kemampuan membalas.

Akibatnya bisa ringan, bisa fatal. Bot yang tadinya lancar bisa berubah diam. Gejalanya membingungkan karena log tetap mencatat pesan masuk, padahal tidak ada balasan yang keluar.

Log bukan bukti bot membalas

Pelajaran ini mahal. Baris log seperti 5 pesan diproses hanya membuktikan separuh hal:

Yang dibuktikan logYang belum dibuktikan
Telegram mengantar pesanProgram membacanya
Offset maju, pesan tidak diulangBot mengirim balasan
Dispatch berjalanBalasan sampai ke chat

Kalau pengguna melaporkan bot tidak merespons, periksa jalur keluar lebih dulu, bukan jalur masuk. Cara paling murah: panggil API Telegram langsung dengan token tersebut memakai curl, lalu lihat apa yang terjadi di sana.

Jangan diamkan kesalahan

Aturan yang murah dan sangat penting: setiap perintah yang tidak dikenali harus mendapat balasan.

perintah = pesan.split("@")[0].lstrip("/").lower()

if perintah in alias:
    tangani(perintah)
elif perintah == "status":
    kirim_status()
else:
    kirim("Perintah tidak dikenal. Daftar: status, tabel, saldo, menu")

Bot yang menjawab “saya tidak tahu” jelas masih hidup. Bot yang tidak menjawab sama sekali akan dianggap mati, dan itu asumsi yang paling mahal karena membuat pengguna menyangka programnya rusak.

Normalisasi sebelum mencocokkan

Pengguna tidak mengetik persis seperti dokumentasi. Ia bisa menulis Status, /status, atau status@Chacha25bot. Ketiganya perintah yang sama. Kalau pencocokan dilakukan mentah-mentah:

Masukan penggunaHarus dianggap sebagai
statusperintah status
Statusperintah status
/STATUSperintah status
status@Chacha25botperintah status
halotidak dikenal, tetap dibalas

Normalisasi harus menjadi baris pertama, sebelum logika apa pun. Detail kecil ini yang menentukan apakah bot terasa|round pintar atau terasa kaku.

Menguji tanpa mengirim apa pun

Jangan langsung menguji program ke Against pengguna. Ganti fungsi pengirim dengan stub yang hanya mencatat:

terkirim = []

def kirim(teks):
    terkirim.append(teks)

# ... jalankan setiap perintah ...

for masukan in (biasanya, kapital, tak_dikenal, bersuffix):
    jalankan(masukan)
    assert terkirim, "masukan tidak dibalas: " + masukan

Untuk bot trading, stub ini jauh lebih penting. Jangan pernah memanggil fungsi yang membuka posisi asli di dalam pengujian. Sekali posisi nyata terbuka, tidak ada tombol batal.

Daftar periksa sebelum menyebut selesai

  1. Proses benar-benar ada — cek PID, bukan hanya “perintah dijalankan”
  2. Log punya isi — proses bisa berstatus jalan padahal keluarannya tertahan buffer
  3. Balasan benar-benar sampai — kirim dari akun lain, bukan dari chat sendiri
  4. Perintah tak dikenal tetap dibalas
  5. Offset tersimpan setelah restart sehingga pesan lama tidak diputar ulang

Penutup

Automasi yang jalan sendiri terasa mengagumkan. Tapi yang bisa diperintah dari Telegram itulah yang sebenarnya berguna. Kalau programnya masih hanya dikendalikan lewat keyboard, itu script yang dijadwalkan, bukan sistem.

Dan bagian yang paling sering terlupakan: program yang diam adalah program yang tidak bisa dipercaya, bukan program yang sedang bekerja dengan baik.

Cara Install Termux di HP Android (2026)

6 Oktober 2026 · 7 menit baca

Termux adalah aplikasi terminal emulator untuk Android yang memungkinkan kamu menjalankan perintah Linux langsung dari HP. Dengan Termux, HP Android bisa berubah seperti komputer mini untuk coding, automation, dan berbagai tugas teknis lainnya.

Kenapa Termux?

Banyak orang mengira untuk membuat website atau menjalankan script, harus punya laptop atau server berbayar. Termux membuktikan hal itu tidak sepenuhnya benar. HP Android yang kamu genggam sudah cukup untuk menjalankan banyak hal yang dulu hanya bisa dilakukan di komputer.

Syarat sebelum install

Sebelum mulai, pastikan HP kamu memenuhi syarat berikut:

  • Android versi 7.0 (Nougat) atau lebih baru
  • Minimal 2 GB RAM (4 GB lebih nyaman)
  • Storage kosong minimal 500 MB
  • Koneksi internet stabil untuk download paket

Langkah 1: Download Termux

Penting: jangan download Termux dari Play Store. Versi di Play Store sudah lama tidak diupdate dan sering tidak berfungsi. Download dari sumber resmi:

  1. Buka F-Droid (toko aplikasi open-source) di browser HP
  2. Download dan install F-Droid dari f-droid.org
  3. Buka F-Droid, cari "Termux"
  4. Klik Install

Alternatif: download APK langsung dari github.com/termux/termux-app/releases

Langkah 2: Setup awal

Setelah Termux terinstall, buka aplikasi dan tunggu beberapa detik. Termux akan menyiapkan environment Linux dasar secara otomatis.

Setelah muncul prompt ketik perintah berikut untuk update paket:

pkg update && pkg upgrade

Tunggu proses download selesai. Mungkin butuh beberapa menit tergantung kecepatan internet.

Langkah 3: Install tools dasar

Setelah update selesai, install tools yang sering dipakai:

pkg install git curl wget nano

Keempat paket ini adalah fondasi untuk hampir semua proyek di Termux:

  • git — untuk upload file ke GitHub
  • curl — untuk download dan testing API
  • wget — alternatif download file
  • nano — editor teks di terminal

Langkah 4: Akses storage HP

Secara default, Termux hanya bisa mengakses folder internalnya. Untuk mengakses folder Download atau Documents di HP, jalankan:

termux-setup-storage

Izin akan muncul, klik Allow. Sekarang folder storage HP bisa diakses dari Termux di ~/storage/.

Langkah 5: Coba perintah pertama

Untuk memastikan semuanya berjalan, coba perintah sederhana:

echo "Termux berhasil diinstall!"

Jika muncul tulisan yang sama, berarti setup berhasil.

Hal yang sering bikin bingung

Termux tertutup saat layar mati? Ini normal. Android membatasi aplikasi background. Untuk menjaga Termux tetap aktif, matikan battery optimization untuk Termux di Settings Android.

Perintah tidak dikenal? Pastikan paket sudah diinstall dengan pkg install nama_paket.

Storage penuh? Termux menyimpan semua datanya di folder internal. Bersihkan dengan pkg clean secara berkala.

Langkah selanjutnya

Setelah Termux terinstall dan berfungsi, kamu bisa mulai membuat blog, menjalankan cron job, atau bahkan mengendalikan program dari Telegram. Semua itu bisa dilakukan langsung dari HP tanpa biaya tambahan.

Termux bukan sekadar aplikasi terminal. Ia adalah pintu masuk HP Android ke dunia Linux, dan semua kemungkinan yang datang dengannya.
